# Support

Use [GitHub Discussions](https://github.com/CedricCaruzzo/mazebench-control-center/discussions)
for setup help, model-server integration questions, and research-workflow
discussion. Search existing discussions and issues before posting.

Use a structured GitHub issue for reproducible bugs or focused feature
requests. Include the Control Center version and sanitized environment details.
Never post API keys, private prompts, raw reasoning traces, or unsanitized run
directories.

Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
Community support is best-effort; no response-time commitment is provided.
